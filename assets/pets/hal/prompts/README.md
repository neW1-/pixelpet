# HAL LED Pet Prompts

Create a 32x32 LED-first pixel-art pet inspired by a HAL-style red camera eye companion:

- black background.
- dark graphite rounded device body.
- central red lens with orange/yellow hot core.
- subtle scan-line or pulse animation.
- no text labels.
- reserve the upper-left 10x10 area for the PixelPet status glyph.

Status glyphs:

- `idle`: dim gray standby dot.
- `working`: cyan/blue spinner or scan mark.
- `needs_input`: blue exclamation mark.
- `permission_required`: orange question mark.
- `done`: green check mark.
- `failed_offline`: red X.

The pet identity should come from the central red eye. Status should always be readable in the upper-left corner.
